## 一、ROI 测算

```
人工研究成本：
  高级分析师时薪 ¥150~300 × 3~8小时 = ¥450~2400 / 次研究

AI 研究成本：
  LLM Token 费用 ≈ $0.5~2.0  （≈ ¥3.5~14）
  Tavily API 费用 ≈ $0.1~0.3 （≈ ¥0.7~2）
  合计 ≈ ¥4~16 / 次

ROI = 节省人力成本 / AI成本 ≈ 100x ~ 150x
```

**注意**：AI 输出仍需人工审核关键数据（约 15-30 分钟），真实节省约为 **70-80% 的研究时间**，而非100%替代。

## 二、目标客户画像

### 优先级 1（最高价值）

- **咨询公司、投行、PE/VC**：研究密集、报告质量要求高、付费能力强，每月研究需求高频稳定
- **大型企业战略/市场部门**：有专职分析团队但仍存在研究积压，对私有化部署接受度高

### 优先级 2（次优）

- **中型企业市场/销售团队**：有研究需求但分析师资源有限，预算相对受限，适合 SaaS 订阅模式
- **媒体/内容机构**：内容产出量大，需要快速建立行业知识背景

### 不适合的客户

- 需要**毫秒级实时数据**的金融交易团队（延迟不可接受）
- 需要**100%精确法律引用**的律所（幻觉风险不可接受）
- 预算极有限的个人用户（API 成本难以承担高频使用）

## 三、与竞品的差异化

| 维度 | RAGFlow Deep Research | Perplexity Deep Research | OpenAI Deep Research |
|---|---|---|---|
| **部署方式** | 私有化可部署 | SaaS only | SaaS only |
| **数据安全** | 数据不出本地 | 数据上云 | 数据上云 |
| **可定制性** | prompt / 模型 / 工具全可改 | 不可定制 | 不可定制 |
| **模型灵活性** | 支持替换任意模型 | 固定模型 | 固定 GPT-4 |
| **与知识库结合** | 可结合 RAGFlow 内部知识库 | 不支持 | 不支持 |
| **输出格式** | 可自定义报告结构 | 固定格式 | 固定格式 |

**核心差异化**：**企业私有化 + 知识库融合 + 完全可定制**，这三点是商业化 SaaS 竞品无法复制的。

| 模式 | 适用客户 | 参考定价 |
|---|---|---|

## 五、商业风险

### 5.1 模型供应商依赖风险

当前模板硬编码两个供应商：
- **通义千问**（阿里云）：qwen-max / qwen-plus
- **Moonshot**（月之暗面）：moonshot-v1-auto / moonshot-v1-128k

风险：
- 用户若无对应 API Key，**开箱即用体验为零**
- 供应商调整定价或 API 接口，模板可能失效
- Moonshot API **在中国以外地区访问受限**，影响国际化

**建议**：销售给国际客户时，提前告知需替换为 OpenAI / Claude 等全球可用模型。

### 5.2 Tavily 工具成本风险

每次完整调用的外部成本：
- TavilySearch：5次搜索
- TavilyExtract：5-8次提取
- Tavily 定价：超出免费额度后约 $5 / 1000次

对于高频使用客户（月均100次以上），Tavily 成本可能超过 LLM 成本，需在报价时单独说明。

### 5.3 数据安全合规风险

研究内容可能涉及竞品、并购意向等敏感商业信息，上传至第三方 API 存在泄露风险。

**建议**：对金融、政府、军工类客户，强推**私有化部署 + 本地搜索工具**方案。

## 六、对 RAGFlow 平台的战略意义

这个模板是 RAGFlow 对外展示**平台能力上限**的旗舰 Demo，同时也是技术能力名片：

- 证明平台支持**复杂多 Agent 编排**
- 证明平台支持**外部工具集成**
- 证明平台支持**长上下文处理**

它的首要价值不是作为独立产品销售，而是作为**企业客户的技术说服工具**——帮助销售团队快速建立技术可信度。

## 七、推荐话术

**对业务决策者**：
> "你告诉我一个研究问题，15分钟后给你一份带数据来源的分析报告，不需要分析师上网搜索整理，成本不到一杯咖啡。"

**对 IT / 安全团队**：
> "完全私有化部署，数据不出公司内网。可以替换成你们自己的模型，Tavily 搜索工具也可以换成内部搜索系统。"

**对采购负责人**：
> "按次收费，不用则不付，没有最低消费。试用一个月，对比分析师人力成本，ROI 一目了然。"
