# Trip Planner — 概览

**对应源文件**：`agent/templates/trip_planner.json`

---

## 这个模板是什么？

Trip Planner 是一个**多 Agent 协作的智能旅行规划系统**：用户描述旅行需求，系统由三个专职 Agent 串行完成行程规划、交通住宿安排、最终整合输出，生成可执行的定制化旅行计划。

```
用户描述旅行需求
    ↓
Tour Guide Agent（制定行程框架）
    ↓
Transit & Stay Agent（搜索交通+住宿，TavilySearch + TavilyExtract）
    ↓
Result Generator（整合输出完整旅行计划）
    ↓
最终旅行计划
```

## 架构一句话

**3 Agent 串行协作 + TavilySearch/Extract**：专职分工（规划→搜索→整合），是消费者 App 场景的多 Agent 标准架构。

---

## 关键特点

- **对话模式**（`mode: "conversational"`）：多轮对话，可以追问细节
- **开场白**："Hi! I'm here to help plan your trip. Any destination in mind?"
- **canvas_type = "Consumer App"**：定位消费者应用场景
- **Transit & Stay Agent 配备双工具**：TavilySearch（搜索）+ TavilyExtract（抓取详情）
