# Market Generate SEO Blog — 概览

**对应源文件**：`agent/templates/market_generate_seo_blog.json`

---

## 这个模板是什么？

Market Generate SEO Blog 是 **generate_SEO_blog 的变体**，架构完全相同——四个串行 Agent 节点自动生成 SEO 博客文章。唯一差异是 `canvas_type`：本模板归属 **Marketing** 分类，在 RAGFlow 模板库中展示在营销场景下。

```
用户输入主题
    ↓
Parse & Keyword Agent（解析意图 + 关键词策略）
    ↓
Outline Agent（生成大纲 + TavilySearch）
    ↓
Body Agent（撰写正文 + TavilySearch）
    ↓
Editor Agent（SEO 审校 + Meta 生成）
    ↓
完整 SEO 博客文章
```

## 架构一句话

**4 Agent 串行线性流水线 + TavilySearch**：固定顺序，行为可预测，适合生产部署。

---

## 与 generate_SEO_blog 的差异

| 维度 | generate_SEO_blog | market_generate_seo_blog |
|---|---|---|
| canvas_type | Agent | Marketing |
| 架构 | 主控 Agent + 3 嵌套子 Agent | 4 个独立串行 Agent 节点 |
| UI 入口 | Agent 分类 | Marketing 分类 |
| 实质差异 | 动态指令分发 | 固定线性顺序 |

> **注意**：`seo_blog` 与本模板架构完全相同，仅 `canvas_type` 为 "Recommended"，详见 [seo_blog 概览](../seo_blog/概览.md)。
