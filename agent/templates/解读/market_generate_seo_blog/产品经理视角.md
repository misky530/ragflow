## 本模板的差异点

### canvas_type = "Marketing"

这意味着用户在 RAGFlow 模板库中，通过 **Marketing（营销）** 分类找到这个模板。

**PM 洞察**：这是一个**渠道差异化**策略——同样的功能，通过不同的分类入口触达不同的用户：
- `generate_SEO_blog`（canvas_type="Agent"）→ 面向了解多 Agent 架构的技术用户
- `market_generate_seo_blog`（canvas_type="Marketing"）→ 面向内容营销团队，从业务场景切入
- `seo_blog`（canvas_type="Recommended"）→ 推荐页面，最大曝光

### 线性 4 节点 vs 主控 Agent 架构

本模板采用 **4 个独立串行 Agent 节点**（Parse & Keyword → Outline → Body → Editor），而非 generate_SEO_blog 的主控 Agent 模式。

**PM 洞察**：对于 Marketing 分类的用户，线性流程更直观——用户能看到每一步在做什么，而不是一个"黑盒主控"统筹所有事情。
