# Customer Review Analysis — 概览

**对应源文件**：`agent/templates/customer_review_analysis.json`

---

## 这个模板是什么？

Customer Review Analysis 是一个**评论自动分类路由系统**：用户提交一条客户评论，系统自动判断情感和问题类型，通过邮件发送给对应的业务部门。

```
客户评论输入
    ↓
第一层分类：正面 / 负面
    ├── 正面 → 发邮件给品牌营销部门
    └── 负面 → 第二层分类：售后问题 / 物流问题
                  ├── 售后问题 → 发邮件给产品体验部门
                  └── 物流问题 → 发邮件给物流部门
    ↓
汇总邮件发送状态 → 输出处理结果
```

## 架构一句话

**两级 Categorize 节点 + 三路 Email 分发**：用决策树替代大模型判断，确定性强、成本低、路由准确。

这个模板有几个值得特别关注的发现：

技术层面：

首次出现 Categorize、Email、StringTransform 三种新节点类型——学习 RAGFlow 节点多样性的好案例
StringTransform 合并三路邮件状态存在边界行为问题：每次只有一路分支执行，另外两路的 @success 变量状态不确定，是个潜在 bug
产品层面：

两级分类设计（情感→问题类型）是比一级三分类更准确的架构思路，值得在其他分类场景复用
业务层面：

邮件作为路由渠道在国内企业场景有明显局限（大多数用企业微信/钉钉），这是落地前必须先确认的关键问题
