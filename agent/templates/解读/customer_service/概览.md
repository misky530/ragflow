# Customer Service — 概览

**对应源文件**：`agent/templates/customer_service.json`

---

## 这个模板是什么？

Customer Service 是一个**多意图智能客服系统**：用户发送问题，系统自动识别意图类型（售前咨询/售后支持/投诉/其他），路由到对应的专业 Agent 处理，最终汇总输出统一回复。

```
用户提问
    ↓
Categorize 节点（4类意图识别）
    ├── 售前咨询 → 售前 Agent（知识库检索）
    ├── 售后支持 → 售后 Agent（知识库检索）
    ├── 投诉处理 → 投诉 Agent（知识库检索）
    └── 其他    → 通用 Agent
    ↓
VariableAggregator（汇合各路输出）
    ↓
统一输出回复
```

## 架构一句话

**Categorize 意图识别 + 并行专业 Agent 分支 + VariableAggregator 汇合**：首次引入 `VariableAggregator` 节点，实现多路分支的输出汇合。
