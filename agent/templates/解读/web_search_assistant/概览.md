**对应源文件**：`agent/templates/web_search_assistant.json`

## 这个模板是什么？

Web Search Assistant 是一个**知识库+网络搜索混合问答系统**：用户提问，系统同时检索内部知识库和公开网络，将两种来源的信息整合后输出权威答案。

```
用户提问
    ↓
Question Refinement Agent（优化问题表述）
    ↓ 并行
├── Web Search Agent（TavilySearch 联网）
└── Retrieval（检索内部知识库）
    ↓
Answer Organizer Agent（整合两路信息，生成最终回答）
    ↓
输出结果
```

## 架构一句话

**问题优化 + 并行双源检索 + 答案整合**：兼顾内部文档权威性与外部网络时效性，是"内部知识 + 实时网络"混合问答的标准架构。
