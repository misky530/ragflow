# Knowledge Base Report — 概览

**对应源文件**：`agent/templates/knowledge_base_report.json`

---

## 这个模板是什么？

Knowledge Base Report 是一个**知识库深度报告生成器**：用户提出一个研究问题，Agent 大规模检索内部知识库，综合多个文档生成一份结构化的深度分析报告，而非简单的单问题回答。

```
用户提出研究问题
    ↓
Agent（qwen3-235b，128K token，内置 Retrieval 工具）
  大范围检索知识库，整合多个文档的内容
    ↓
输出：结构化深度分析报告（非单问题问答）
```

## 架构一句话

**超大模型（qwen3-235b / 128K token）+ 内置 Retrieval**：用顶级大模型处理大量检索内容，是 `technical_docs_qa` 的**深度报告升级版**——从"问答"升级到"研究报告"。
