# User Interaction — 概览

**对应源文件**：`agent/templates/user_interaction.json`

---

## 这个模板是什么？

User Interaction 是一个**人机协作审批流程**模板：AI 制定计划后，暂停等待人工确认，用户批准后才继续执行后续搜索和输出。

```
用户提问
    ↓
Planning Agent（制定研究计划/执行方案）
    ↓
UserFillUp 节点（暂停，等待人工审批）
    ↓ 用户确认/修改后继续
Search Agent（执行搜索，生成最终回答）
    ↓
输出结果
```

## 架构一句话

**双 Agent + UserFillUp 人工节点**：RAGFlow 模板库中唯一引入**人工审批节点**的模板，展示了"AI 规划 → 人工把关 → AI 执行"的 Human-in-the-Loop 架构。
