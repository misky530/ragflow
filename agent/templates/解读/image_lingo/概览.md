# Image Lingo — 概览

**对应源文件**：`agent/templates/image_lingo.json`

---

## 这个模板是什么？

Image Lingo 是 RAGFlow 模板库中**唯一的多模态（图文）处理模板**：用户上传图片，Agent 理解图片内容并回答问题或生成描述。

```
用户上传图片 + 文字提问
    ↓
多模态 Agent（qwen-vl-plus，同时理解图文）
    ↓
基于图片内容的回答/分析/描述
```

## 架构一句话

**单 Agent + 视觉语言模型（VLM）**：用 `visual_files_var=sys.files` 将上传的图片文件传入多模态模型，是 RAGFlow 视觉能力的最简展示。
