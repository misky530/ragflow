# E-commerce Customer Service Workflow — 概览

**对应源文件**：`agent/templates/ecommerce_customer_service_workflow.json`

---

## 这个模板是什么？

电商专属客服工作流：根据用户咨询类型，自动路由到不同分支，每个分支先检索对应知识库，再由 Agent 生成专业回答。

```
用户提问
    ↓
Categorize（3类：订单/产品/其他）
    ├── 订单相关 → Retrieval（订单知识库）→ Agent → Message
    ├── 产品相关 → Retrieval（产品知识库）→ Agent → Message
    └── 其他    → Retrieval（通用知识库）→ Agent → Message
```

## 架构一句话

**Categorize + 各分支独立 Retrieval → Agent**：是 customer_service/support 的**电商垂直版**，在每个分支内部各有一个独立 Retrieval 节点，强调知识库隔离和检索可控。
