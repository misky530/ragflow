## 这个模板是什么？

Generate SEO Blog 是一个**多 Agent 协作的 SEO 博客生成系统**：用户输入主题，系统自动联网搜索参考资料，由三个专职 Agent 依次完成大纲生成、正文撰写、编辑润色，输出一篇完整的 SEO 优化博客文章。

```
用户输入主题
    ↓
Lead Agent（统筹协调）
    ├── Outline Agent（生成文章大纲）+ TavilySearch
    ├── Body Agent（根据大纲写正文）
    └── Editor Agent（SEO 优化和润色）
    ↓
完整 SEO 博客文章
```

## 架构一句话

**多 Agent 串行协作 + TavilySearch**：Outline → Body → Editor 三阶段流水线，是内容创作自动化的标准架构。
