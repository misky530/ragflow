# Generate SEO Blog — 开发者视角

---

## 一、架构概览

```
begin → Lead Agent（deepseek-chat，orchestrator）
           ├── Outline Agent（子 Agent，deepseek-chat + TavilySearch）
           ├── Body Agent（子 Agent，deepseek-chat + TavilySearch）
           └── Editor Agent（子 Agent，deepseek-chat）
               ↓
         Message（输出完整博客）
```

**架构类型**：主控 Agent + 3 个嵌套子 Agent，串行调用

---

## 二、节点详解

### Lead Agent（主控）
- `llm_id`: `deepseek-chat@DeepSeek`
- `temperature`: 0.1（精确，控制指令输出的一致性）
- `max_rounds`: 3
- **核心职责**：解析用户意图，生成写作计划，向 3 个子 Agent 派发指令，合并最终输出
- **输出格式**：Parsed Writing Plan + 三段 Instructions（for Outline/Body/Editor Agent）

### Outline Agent（子 Agent）
- `llm_id`: `deepseek-chat@DeepSeek`
- `temperature`: 0.5（适度创意，允许结构探索）
- `frequency_penalty`: 0.3
- `max_rounds`: 2
- **工具**：TavilySearch（搜索深度 basic，max_results 5，include_raw_content true）
- **职责**：基于 Lead Agent 指令生成 H2/H3 结构大纲，每节附带关键词建议

### Body Agent（子 Agent）
- `llm_id`: `deepseek-chat@DeepSeek`
- **工具**：TavilySearch（按需搜索补充例子）
- **职责**：按大纲逐节撰写正文，每节 500-600 词，SEO 优化

### Editor Agent（子 Agent）
- `llm_id`: `deepseek-chat@DeepSeek`
- **职责**：SEO 审校，关键词密度调整，标题层级验证，生成 meta title + meta description

---

## 三、数据流

```
sys.query → Lead Agent 解析意图
    → Lead Agent 调用 Outline Agent（工具调用模式）
        → Outline Agent 可选调用 TavilySearch
        → 返回结构化大纲
    → Lead Agent 调用 Body Agent
        → Body Agent 可选调用 TavilySearch
        → 返回全文草稿
    → Lead Agent 调用 Editor Agent
        → 返回润色后全文 + meta 信息
    → Lead Agent 合并输出 Markdown
→ Message 展示
```

**关键设计**：子 Agent 通过 Lead Agent 的 `tools` 列表注册，Lead Agent 以函数调用方式触发子 Agent，并在 `sys_prompt` 中定义每个子 Agent 的角色和输出格式。

---

## 四、关键参数配置

| 参数 | 值 | 说明 |
|---|---|---|
| Lead Agent temperature | 0.1 | 指令生成需要精确，不能发散 |
| Outline Agent temperature | 0.5 | 允许适度创意探索结构 |
| TavilySearch search_depth | basic | 快速检索，非深度爬取 |
| TavilySearch include_raw_content | true | 返回原始内容供 Agent 参考 |
| Lead Agent max_rounds | 3 | 允许多轮协调 |
| Outline/Body Agent max_rounds | 2-3 | 限制单 Agent 轮次控制成本 |

---

## 五、与 market_generate_seo_blog / seo_blog 的差异

| 维度 | generate_SEO_blog（本模板） | market_generate_seo_blog / seo_blog |
|---|---|---|
| canvas_type | Agent | Marketing / Recommended |
| 架构 | 主控 Agent + 嵌套子 Agent | 4 个独立串行 Agent 节点 |
| 协调方式 | Lead Agent 动态指令分发 | 固定线性顺序 |
| 灵活性 | Lead Agent 可动态调整流程 | 流程固定，更可预测 |

**开发者洞察**：本模板的嵌套架构适合需要动态判断的场景（如 Lead Agent 根据意图选择不同写作策略）；market/seo_blog 的线性架构更适合生产环境（行为可预测、易调试）。

---

## 六、部署要点

```
1. 配置 TavilySearch API Key（Outline Agent 和 Body Agent 都需要）
2. 确认 DeepSeek API 额度（3 个子 Agent 串行调用，token 消耗较大）
3. Lead Agent max_rounds=3 是瓶颈，若子 Agent 响应慢可能超时
4. 测试建议：先用简单主题（如"什么是 RAG"）验证全链路
5. 中文支持：所有 Agent prompt 均为英文，但 DeepSeek 对中文输入有良好支持
```
