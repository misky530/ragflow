## 这个模板是什么？

Technical Docs QA 是 RAGFlow 模板库中**最简洁的知识库问答模板**：用户提问，Agent 检索企业内部技术文档知识库，给出基于文档的精准回答。

```
用户提问
    ↓
Agent（内置 Retrieval 工具，检索知识库）
    ↓
基于文档内容的回答
```

## 架构一句话

**单 Agent + 内置 Retrieval**：最小可用的 RAG 问答架构，是理解 RAGFlow 知识库问答能力的最佳入门模板。
