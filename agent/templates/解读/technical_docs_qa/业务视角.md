# Technical Docs QA — 业务视角

---

## 一、ROI 测算

```
人工查文档成本：
  工程师/支持人员时薪 ¥80~150 × 每次查询 5~15 分钟
  每天 20 次查询 = 1.5~5 小时/人/天

AI 查询成本：
  LLM token 费用极低，每次查询约 ¥0.01~0.05
  20次/天 = ¥0.2~1/天

ROI ≈ 数百倍（成本）+ 响应时间从分钟级降至秒级
```

## 二、目标客户画像

| 客户类型 | 痛点 | 优先级 |
|---|---|---|
| **技术产品公司**（SaaS/开发者工具） | 支持团队频繁查文档，新人培训周期长 | ★★★★★ |
| **系统集成商/IT服务商** | 为多个客户维护复杂系统，技术文档量大 | ★★★★☆ |
| **大型企业 IT 部门** | 内部技术规范文档多，查询效率低 | ★★★★☆ |
| **硬件制造商** | 产品手册/维修手册查询频繁 | ★★★☆☆ |

## 三、核心销售话术

**对技术负责人**：
> "你们的新工程师要多久才能熟悉内部文档体系？这个工具能让他们第一天就能精准查到任何技术细节，还有文档来源可以核对。"

**对客服/支持团队负责人**：
> "支持工单里有多少是可以从文档里找到答案的？把文档库接进来，客服直接问 AI，不用每次都问资深工程师。"

## 四、定价建议

| 模式 | 适用 | 参考价 |
|---|---|---|
| 知识库建设 + 模板部署 | 一次性交付 | ¥8000~30000（含文档整理和系统部署） |
| 年度维护（知识库更新） | 文档频繁更新的客户 | ¥3000~10000/年 |

**关键卖点**：一次建库，长期受益。新员工培训成本和支持团队查询时间节省，通常3个月内回本。
