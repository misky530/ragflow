# Stock Research Report — 开发者视角

---

## 一、节点类型全景（引入最多新节点类型的模板）

| 节点类型 | 实例 | 作用 | 是否新出现 |
|---|---|---|---|
| `Begin` | begin | 接收股票代码/公司名 | — |
| `Agent` | 代码提取 Agent | 从用户输入提取有效股票代码 | — |
| `Switch` | 有效性分流 | 判断股票代码有效/无效，路由到不同分支 | **首次出现** |
| `Agent` (MCP) | 研报 Agent | 通过 MCP 检索分析师研报 | — |
| `Tool` | YahooFinance | 获取股票行情、财务数据 | **首次出现** |
| `CodeExec` | 图表生成 | 执行 Python 代码生成数据图表 | **首次出现** |
| `Agent` | 综合报告 Agent | 整合所有数据，生成最终报告 | — |
| `Message` | 输出节点 | 展示报告和图表 | — |

## 二、数据流分析

```
begin
  └── sys.query（用户输入的股票信息）
          │
          ↓
代码提取 Agent
  任务：从输入中识别和规范化股票代码
  输出：@ticker（如 "AAPL", "600519.SS"）
          │
          ↓
Switch 节点（条件路由）
  条件1：ticker 有效（非空，格式正确）→ 继续执行
  条件2：ticker 无效 → Message（提示重新输入）
          │（有效分支）
          ├─────────────────────────┐
          ↓                         ↓
YahooFinance 工具              MCP 研报 Agent
  输入：@ticker                输入：@ticker
  获取：                       任务：检索分析师研报
    - 实时/延迟行情              输出：@report_content
    - 财务摘要数据
    - 历史价格数据
  输出：@market_data
          │                         │
          └─────────┬───────────────┘
                    ↓
            CodeExec 节点
            输入：@market_data（历史价格等数值数据）
            执行：Python 代码（matplotlib/plotly 生成图表）
            输出：@chart（图表文件或 base64 图片）
                    │
                    ↓
            综合报告 Agent
            输入：
              - @ticker（股票代码）
              - @market_data（财务数据）
              - @report_content（研报内容）
              - @chart（图表）
            任务：整合所有信息，生成结构化研究报告
            输出：@final_report
                    │
                    ↓
            Message → 用户界面
```

## 三、Switch 节点工作机制

`Switch` 是 RAGFlow 的**条件分支节点**，类似编程中的 switch-case：

```
Switch 节点配置：
  条件1（默认分支）：
    变量：@ticker
    操作：is not empty
    目标节点：并行数据获取

  条件2（else 分支）：
    目标节点：错误提示 Message
```

与 `Categorize` 的区别：
- `Categorize`：用 LLM 判断分类（语义理解）
- `Switch`：用规则判断条件（精确匹配，无需 LLM，成本极低）

## 四、CodeExec 节点详解

`CodeExec` 允许在工作流中执行任意 Python 代码：

```python
# 示例：生成股价走势图
import matplotlib.pyplot as plt
import json

data = json.loads(market_data)  # 来自 YahooFinance 的数据
prices = data['history']['Close']

plt.figure(figsize=(10, 4))
plt.plot(prices)
plt.title(f"{ticker} - 近期走势")
plt.savefig('/tmp/chart.png')
```

**安全注意事项**：
- CodeExec 执行任意代码，需要在**沙箱环境**中运行
- 确认 RAGFlow 部署是否启用了代码沙箱（见 `docker/service_conf.yaml` 中的 sandbox 配置）
- 不要在生产环境对外暴露未经审查的代码执行能力

## 五、YahooFinance 工具配置

YahooFinance 是 RAGFlow 内置工具（通过 `yfinance` Python 库实现），返回：
- 股票基本信息（公司名、市值、PE、PB 等）
- 历史价格数据（可指定时间范围）
- 财务报表摘要（营收、净利润、现金流）

**局限**：
- 数据有 15-20 分钟延迟（免费 API）
- A 股代码格式为 `600519.SS`（沪）/ `000858.SZ`（深），非中国用户习惯的格式
- 部分财务数据对中国公司覆盖不完整

## 六、落地配置

```
1. 确认 CodeExec 沙箱环境配置
   检查：docker/service_conf.yaml 中 sandbox 相关配置

2. 导入模板，验证各节点配置：
   - YahooFinance 工具是否在工具列表中可用
   - MCP 研报服务是否已配置（需要外部研报数据源）
   - CodeExec 需要的 Python 库是否已安装（matplotlib, yfinance 等）

3. 测试流程：
   - 输入美股代码（如 AAPL）验证完整流程
   - 输入 A 股代码（如 600519.SS）验证数据覆盖情况
   - 输入无效代码验证 Switch 的错误处理分支
```
