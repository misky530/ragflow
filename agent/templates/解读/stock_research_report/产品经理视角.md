# Stock Research Report — 产品经理视角

---

## 一、目标用户与核心痛点

| 用户类型 | 核心需求 | 当前痛点 |
|---|---|---|
| 个人投资者 | 快速了解一只股票的基本面和市场观点 | 研报付费贵、读不懂；自己查数据费时费力 |
| 买方研究员 | 快速生成覆盖个股的初步研究框架 | 每只股票的基础资料整理耗时 2-4 小时 |
| 财富管理顾问 | 为客户快速生成持仓股票分析报告 | 依赖研究部门，响应慢，报告同质化 |
| 量化/数据团队 | 批量生成股票研究数据 | 人工研究无法规模化 |

**核心价值主张**：输入一个股票代码，几分钟后得到一份整合了行情数据、财务指标和分析师观点的结构化研究报告。

## 二、功能设计的 PM 逻辑

### 2.1 Switch 节点 — 输入验证的产品级处理

在获取数据之前，先验证股票代码是否有效，无效则提前终止并提示用户。

**PM 洞察**：这是**防御性产品设计**。如果直接调用 YahooFinance 查询无效代码，会得到空数据或错误，后续报告生成会失败。Switch 节点提前做了"输入合法性"的用户引导，提升了使用体验。

### 2.2 并行数据获取 — 效率与数据多元化

`YahooFinance`（实时市场数据）和 `MCP 研报 Agent`（分析师观点）**并行执行**，而非串行。

**PM 洞察**：两种数据源是互补的——行情数据客观，研报观点主观。并行执行一方面缩短了总耗时，另一方面体现了"量化数据 + 定性分析"的投研思路。

### 2.3 CodeExec — AI 报告中的可视化能力

`CodeExec` 节点执行 Python 代码，动态生成价格走势图、财务指标对比图等。

**PM 洞察**：这是这个模板最有差异化的功能。大多数 AI 生成的报告只有文字，而这里能生成真实的数据图表，大幅提升了报告的专业感和可信度。

## 三、产品边界

### 适用场景
- 个股快速研究（上市公司基本面分析）
- 投资决策的辅助参考材料
- 客户会议前的股票背景资料准备

### 不适用场景

| 场景 | 原因 |
|---|---|
| **作为投资建议使用** | AI 生成报告不构成投资建议，存在法律风险 |
| **高频交易决策** | YahooFinance 数据有延迟，非实时行情 |
| **A 股非主流股票** | YahooFinance 对 A 股数据覆盖有限 |
| **替代专业研究团队** | AI 报告缺乏对公司管理层、行业深度的判断 |

## 四、产品成熟度评估

| 评估维度 | 评分 | 说明 |
|---|---|---|
| **概念创新性** | ★★★★★ | 架构最复杂，展示了最多节点类型 |

| **合规风险控制** | ★★☆☆☆ | 缺乏明确的免责声明机制 |
| **开箱即用性** | ★★☆☆☆ | 需配置 YahooFinance + MCP 研报服务 |

## 五、迭代方向建议

1. **A 股数据源适配**：替换 YahooFinance 为同花顺/东方财富 API，支持 A 股
2. **免责声明自动插入**：报告末尾自动添加"本报告由 AI 生成，不构成投资建议"
3. **报告模板定制**：支持不同机构风格（买方研究/卖方研究/财富管理）
4. **批量生成**：支持一次性生成多只股票的对比报告
