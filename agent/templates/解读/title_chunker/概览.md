# Title Chunker — 概览

**对应源文件**：`agent/templates/title_chunker.json`

---

## 这个模板是什么？

Title Chunker 是一个**标题结构化切片流水线**：按文档标题层级（H1/H2/H3/H4）切分文档，每个切片是完整的"标题+正文"组合，适合有清晰标题层级的结构化文档。

```
File（上传文档：PDF/Word/Markdown）
    ↓
Parser（输出 json 格式，保留结构信息）
    ↓
HierarchicalMerger（按标题正则切分：H1/H2/H3/H4，层级=3）
    ↓
Tokenizer（fields="text"，建立全文+向量双索引）
```

## 架构一句话

**Parser(json) → HierarchicalMerger(4级标题) → Tokenizer**：不做 LLM 增强，直接按文档结构切片——速度最快、成本最低、适合结构化文档。

---

## HierarchicalMerger 的标题匹配规则

```
Level 0（H1）：正则 "^#[^#]"    → 匹配 "# 一级标题"
Level 1（H2）：正则 "^##[^#]"   → 匹配 "## 二级标题"
Level 2（H3）：正则 "^###[^#]"  → 匹配 "### 三级标题"
Level 3（H4）：正则 "^####[^#]" → 匹配 "#### 四级标题"
hierarchy=3：每片合并到第 3 层深度
```
