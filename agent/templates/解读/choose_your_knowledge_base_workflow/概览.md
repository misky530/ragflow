# Choose Your Knowledge Base Workflow — 概览

**对应源文件**：`agent/templates/choose_your_knowledge_base_workflow.json`

---

## 这个模板是什么？

与 `choose_your_knowledge_base_agent` 功能相同——用户选择知识库后进行问答——但采用的是 **Workflow 架构**：Retrieval 作为独立节点，执行顺序由图引擎强制控制，而非由 Agent 自主决定。

```
用户选择知识库 + 提问
    ↓
Retrieval 节点（按选定知识库强制检索）
    ↓
Agent（接收检索结果，生成回答）
    ↓
输出
```

## 架构一句话

**Begin 下拉选择 + 独立 Retrieval 节点 + Agent**：流程固定可控，检索与生成职责分离，是 `choose_your_knowledge_base_agent` 的 Workflow 替代方案。
