# Knowledge Base Report (Recommended) — 概览

**对应源文件**：`agent/templates/knowledge_base_report_r.json`

---

## 这个模板是什么？

与 `knowledge_base_report` **功能完全相同**，唯一区别是 `canvas_type` 字段：

| 字段 | knowledge_base_report | knowledge_base_report_r |
|---|---|---|
| `canvas_type` | `"Other"` | `"Recommended"` |

`canvas_type = "Recommended"` 意味着这个版本会在 RAGFlow 的模板选择界面中被标记为**官方推荐**，排序靠前，更容易被用户发现。

## 架构一句话

与 `knowledge_base_report` 完全一致，仅展示方式不同——是同一个模板的**推荐位版本**。

## 设计含义（PM 洞察）

RAGFlow 提供两个版本的模板：
- `Other` 类型：在"其他"分类下，面向愿意探索的用户
- `Recommended` 类型：在推荐位展示，降低用户发现成本

这是**内容运营策略**的体现——通过 `canvas_type` 控制模板的曝光权重，引导用户优先使用经过充分验证的成熟模板。`_r` 后缀就是 "Recommended" 的缩写。
