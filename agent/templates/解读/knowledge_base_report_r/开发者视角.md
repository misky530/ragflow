# Knowledge Base Report (Recommended) — 开发者视角

> 此模板与 `knowledge_base_report` 的节点结构、配置参数完全相同。
> 完整技术分析请参阅：[../knowledge_base_report/开发者视角.md](../knowledge_base_report/开发者视角.md)

---

## 唯一技术差异

```json
// knowledge_base_report.json
{ "canvas_type": "Other" }

// knowledge_base_report_r.json
{ "canvas_type": "Recommended" }
```

`canvas_type` 是 RAGFlow 前端用于**模板分类和排序**的元数据字段，不影响任何运行时行为。

---

## 对开发者的意义

如果你在开发自定义模板并希望控制展示位置：
- 设置 `canvas_type = "Recommended"` → 出现在推荐位，曝光度高
- 设置 `canvas_type = "Other"` → 归入其他分类，适合测试阶段
- 其他已知值：`"Customer Support"`, `"Marketing"`, `"Consumer App"` 等垂直分类
