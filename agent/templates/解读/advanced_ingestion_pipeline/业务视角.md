# Advanced Ingestion Pipeline — 业务视角

---

## 一、核心价值

```
基础 RAG 知识库：
  问题："公司的退款政策是什么？"
  召回：返回包含"退款"的文本片段（可能包含大量无关内容）
  精准度：中等

Advanced Ingestion Pipeline 知识库：
  问题：同上
  召回：通过 questions 字段（预生成"关于退款政策的问题"）精准匹配
  精准度：高（问答语义对齐）

价值：知识库问答精准率显著提升，减少"答非所问"
```

---

## 二、目标客户

| 客户类型 | 适合程度 | 说明 |
|---|---|---|
| **大型企业知识库** | ★★★★★ | 文档量大，对召回精度要求高 |
| **智能客服平台** | ★★★★★ | 问答对齐是客服 RAG 的核心需求 |
| **法律/合规文档检索** | ★★★★☆ | 元数据过滤（日期、条款编号）价值大 |
| **医疗/保险知识库** | ★★★★☆ | 多维检索确保专业内容准确召回 |
| **小型企业简单 Q&A** | ★★☆☆☆ | 摄取成本偏高，不值得 |

---

## 三、销售话术

**对企业知识库负责人**：
> "你们现在的知识库问答准确率怎么样？用户能找到他们想要的信息吗？Advanced Ingestion Pipeline 在文档入库时就为每个段落生成摘要、关键词和预设问题——这样用户问的问题和库里的内容更容易匹配，减少了'答非所问'的情况。"

---

## 四、关键权衡

| 权衡 | 说明 |
|---|---|
| **高召回质量 vs 高摄取成本** | 比基础摄取贵 10-20 倍，但召回质量大幅提升 |
| **适合批量摄取，不适合实时** | 大文档摄取可能需要几分钟，不能用于实时场景 |
| **需要持续 LLM API 调用** | 运营成本要纳入知识库TCO计算 |

---

## 五、一句话总结

> Advanced Ingestion Pipeline 是**高精度知识库的摄取方案**：四类 LLM 增强字段（摘要/关键词/问答/元数据）让同一批文档支持所有主流检索策略，是企业级 RAG 知识库从"能用"到"好用"的关键升级路径。
