# Advanced Ingestion Pipeline — 概览

**对应源文件**：`agent/templates/advanced_ingestion_pipeline.json`

---

## 这个模板是什么？

Advanced Ingestion Pipeline 是一个**增强型文档摄取流水线**：对每个文本切片同时生成摘要、关键词、问答、元数据四类衍生字段，让同一批文档支持多种检索策略（关键词/向量/语义问答/元数据过滤）。

```
File（上传文档）
    ↓
Parser（DeepDoc 解析，输出 markdown）
    ↓
Splitter（512 tokens，换行分割）
    ↓
Extractor:summary（生成每片摘要）
    ↓
Extractor:keywords（提取 Top 5 关键词）
    ↓
Extractor:questions（生成 3 个代表性问题）
    ↓
Extractor:metadata（提取结构化元数据 JSON）
    ↓
Tokenizer（建立全文+向量双索引，索引字段: text）
```

## 架构一句话

**串行 4 Extractor 增强 + Tokenizer 双索引**：是 RAGFlow 摄取管道中功能最完整的模板，适合对召回质量有高要求的场景。

---

## 与基础模板的对比

| 模板 | 增强字段 | 摄取复杂度 | 召回多样性 |
|---|---|---|---|
| 无 Ingestion Pipeline | 无 | 最低 | 低 |
| `chunk_summary` | summary | 低 | 中 |
| `advanced_ingestion_pipeline`（本模板） | summary + keywords + questions + metadata | 高 | 高 |
| `title_chunker` | 无（结构化切片） | 中 | 中（按标题结构） |
