# Deep Search R — 业务视角

---

## 一、核心价值

```
传统战略研究：
  初级顾问完成一份市场分析报告：2~3 天
  咨询公司外包：¥5000~50000/份报告

使用此模板：
  输入研究课题 → 10~15 分钟生成 2000 字 McKinsey 风格报告
  成本：qwen-max + Tavily API（约 ¥5~20/次）

价值：研究时间压缩 95%，成本下降 99%
      定位：专业研究的"初稿加速器"，不是替代品
```

## 三、销售话术

**对咨询公司**：
> "你们的初级顾问每周能完成几份市场研究初稿？有了这个 AI 研究助手，他们只需要设定研究问题，10 分钟后就有一份 2000 字、带引用来源的初稿——他们的时间可以用来做更有价值的分析和客户沟通，而不是信息收集。"

**对企业战略部门**：
> "你们领导要求一周内给出某个市场的竞争态势分析？以前可能要花 3 天，现在这个工具可以在 15 分钟内给出框架报告，你们再花 1~2 天深化就能交付。"

---

## 四、定位说明

**Deep Search R 是"初稿加速器"，不是"研究替代品"**：
- AI 生成的报告基于公开互联网信息，缺乏行业内部数据和专家访谈
- 质量足够作为讨论基础和框架，不能直接作为最终交付物
- 适合"80分初稿 → 人工优化到 95分"的工作模式
