## 这个模板是什么？

Deep Search R 是**企业级深度研究 Agent**：主控 Agent（qwen-max）接收用户研究需求，动态协调三个专职子 Agent 完成 URL 发现、内容深度阅读、战略报告撰写，输出麦肯锡风格的 2000 字专业研究报告。

```
用户输入研究课题
    ↓
Strategy Research Director（qwen-max，主控 orchestrator）
    ├── Web Search Specialist（qwen-plus + TavilySearch，发现 5 个优质 URL）
    ├── Content Deep Reader（读取 URL 内容，结构化提取）
    └── Research Synthesizer（撰写战略报告）
    ↓
Message（输出完整研究报告）
```

## 架构一句话

**主控 Agent（qwen-max）+ 3 嵌套子 Agent**：动态查询分类（深度优先/广度优先/直接查找）+ 三阶段质量门控，是深度研究任务的企业级方案。

## 与 deep_research 的差异

| 维度 | deep_research | deep_search_r |
|---|---|---|
| canvas_type | Recommended | Agent |
| 主模型 | - | qwen-max@Tongyi-Qianwen |
| 研究方法论 | 基础 | 详细（深度优先/广度优先/直接查找分类）|
| 质量门控 | - | 3 个阶段明确质量检查标准 |
| 报告标准 | 一般 | McKinsey/BCG/Deloitte 风格，约 2000 字 |
| prompt 复杂度 | 中等 | 极高（含完整执行框架、示例、自适应策略）|
