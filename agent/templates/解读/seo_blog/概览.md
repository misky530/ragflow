# SEO Blog — 概览

**对应源文件**：`agent/templates/seo_blog.json`

---

## 这个模板是什么？

SEO Blog 是 **market_generate_seo_blog 的推荐版本**，架构和功能完全相同——4 个串行 Agent 节点自动生成 SEO 博客文章。唯一差异是 `canvas_type = "Recommended"`，使其出现在 RAGFlow 模板库的**推荐首页**。

```
用户输入主题
    ↓
Parse & Keyword Agent → Outline Agent → Body Agent → Editor Agent
    ↓
完整 SEO 博客文章（含 meta title + description）
```

## 架构一句话

**4 Agent 串行线性流水线 + TavilySearch**：与 market_generate_seo_blog 架构完全相同，canvas_type 决定 UI 展示位置。

---

## 与其他 SEO Blog 变体的对比

| 模板 | canvas_type | 架构 | 核心差异 |
|---|---|---|---|
| `seo_blog`（本模板） | Recommended | 4 节点串行 | 出现在推荐首页，曝光最高 |
| `market_generate_seo_blog` | Marketing | 4 节点串行 | 出现在 Marketing 分类 |
| `generate_SEO_blog` | Agent | 主控+嵌套 | 出现在 Agent 分类，架构不同 |

> **结论**：`seo_blog` 是三者中**入门门槛最低、曝光最高**的版本。功能分析完全参考 market_generate_seo_blog。
