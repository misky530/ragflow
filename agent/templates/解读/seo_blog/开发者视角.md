# SEO Blog — 开发者视角

---

> 本模板与 `market_generate_seo_blog` 架构完全相同（仅 `canvas_type` 不同）。
> 完整技术分析详见 [market_generate_seo_blog 开发者视角](../market_generate_seo_blog/开发者视角.md)。

---

## 唯一技术差异

```json
"canvas_type": "Recommended"  // seo_blog
"canvas_type": "Marketing"    // market_generate_seo_blog
```

`canvas_type` 是纯 UI 展示字段，不影响任何运行时行为、节点配置或数据流。

---

## 节点结构（同 market_generate_seo_blog）

```
begin
  ↓
Parse & Keyword Agent（deepseek-chat，max_rounds=1）
  ↓
Outline Agent（deepseek-chat + TavilySearch，max_rounds=3）
  ↓
Body Agent（deepseek-chat + TavilySearch，max_rounds=5）
  ↓
Editor Agent（deepseek-chat）
  ↓
Message
```
