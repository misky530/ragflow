## 这个模板是什么？

CV Analysis 是一个**批量简历筛选系统**：HR 上传 JD 和一批简历文件，系统自动逐份评估，每份输出标准化的结构化摘要和 JD 匹配评分。

```
HR 输入 JD 文字 + 上传简历文件（批量）
    ↓
对每份简历自动提取 6 个标准字段：
  姓名 / 联系方式 / 学历 / 工作年限 / 所在城市 / JD 匹配分析
    ↓
每份简历输出 0-10 分的匹配评分 + 匹配点和差距说明
    ↓
聊天界面按顺序展示所有候选人评估结果
```

## 架构一句话

**单 Agent + Iteration 容器**：最轻量的批处理架构，无外部工具依赖，1个 API Key 即可运行。
