# SQL Assistant — 概览

**对应源文件**：`agent/templates/sql_assistant.json`

---

## 这个模板是什么？

SQL Assistant 是一个**自然语言转 SQL 并执行的数据库问答系统**：用户用中文/英文提问，系统自动理解数据库结构、生成 SQL 查询并执行，返回数据结果。

```
用户用自然语言提问（"今天销售额最高的产品是什么？"）
    ↓
3个 Retrieval 节点并行检索（表结构/字段说明/查询示例）
    ↓
Agent（Text-to-SQL，根据检索到的 Schema 生成 SQL）
    ↓
ExeSQL 节点（执行 SQL，返回真实数据）
    ↓
格式化输出结果
```

## 架构一句话

**并行 Retrieval + Text-to-SQL Agent + ExeSQL**：引入了 RAGFlow 模板库中唯一的 `ExeSQL` 执行节点，实现从自然语言到真实数据库查询的完整闭环。
