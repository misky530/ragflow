# Choose Your Knowledge Base Agent — 概览

**对应源文件**：`agent/templates/choose_your_knowledge_base_agent.json`

---

## 这个模板是什么？

这是一个**用户自选知识库的智能问答 Agent**：在对话开始时，用户通过下拉菜单选择要查询的知识库，Agent 根据选择在对应知识库中检索回答。

```
用户选择知识库（下拉菜单）+ 提问
    ↓
Agent（内置 Retrieval 工具，检索所选知识库）
    ↓
基于选定知识库的回答
```

## 架构一句话

**Begin 下拉选择 + Agent 内置 Retrieval**：通过 Begin 节点的下拉参数实现多知识库动态切换，是 `technical_docs_qa` 的多知识库扩展版。
