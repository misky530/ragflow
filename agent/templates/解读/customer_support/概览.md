# Customer Support — 概览

**对应源文件**：`agent/templates/customer_support.json`

---

## 这个模板是什么？

Customer Support 与 `customer_service` 功能高度相似，同为多意图客服路由系统，但架构上有关键差异：**没有 VariableAggregator 节点**，各分支 Agent 直接连接到 Message 节点输出。

```
用户提问
    ↓
Categorize 节点（多类意图识别）
    ├── 分支1 → Agent → Message
    ├── 分支2 → Agent → Message
    └── 分支N → Agent → Message
```

## 架构一句话

**Categorize + 多路 Agent，各分支直通 Message**：相比 customer_service 的 VariableAggregator 汇合方式，这种架构更直接，但依赖 RAGFlow 的条件输出机制保证只激活一路 Message。
